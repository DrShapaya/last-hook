# Last Hook — карта проекта и дизайна

Обновлено 22 октября 2026 года. Текущий прототип — **0.15.1**, Godot 4.7.2, Android/Windows. Три экспедиции по три акта с опасностями (генератор v15), пять типов зацепов, монеты, активные предметы и экономика v15, профиль сохранения v6. Полный аудит кода и визуала с планом исправлений — [AUDIT_LAST_HOOK.md](AUDIT_LAST_HOOK.md). Остальная редакция дизайна задаёт последующие этапы; исполненное отделено в 07.

Last Hook — восхождение на одном крюке: выбрать опору, подготовить движение, отпустить канат, перелететь и зацепиться снова. Основа качества — приятная инерция, читаемый маршрут и осмысленный риск. После поражения новая попытка начинается снизу; оснащение сохраняется.

## Запуск и структура

- `Play.cmd` — локальный запуск; `PreviewSource.cmd` — из текущих исходников; `OpenEditor.cmd` — редактор.
- `PreviewAnimations.cmd` — просмотр анимаций персонажа.
- `game/` — действующий проект; [balance.json](game/data/balance.json) — текущие числа.
- `Builds/Windows/LastHook.exe`, `Builds/Android/LastHook-debug.apk` — локальные тестовые сборки; `Release.cmd` — подписанный релизный APK в `Builds/Versions/v<версия>/`.
- [tools/build.ps1](tools/build.ps1) — импорт, 19 наборов автоматических проверок и экспорт. Полная сборка: `./tools/build.ps1 -Target All`.
- `docs/validation/` — сохранённые автоматические отчёты; `docs/screenshots/` — кадры из движка; `artifacts/` — локальные журналы и отчёты (вне git).
- [README.md](README.md) — запуск и история изменений; [07](07_prototype_status.md) — статус проверенной сборки.

Реклама — Yandex Ads, см. [docs/ADS.md](docs/ADS.md); реальные платежи не подключены. Проверки ботом не подтверждают человеческую сложность, интерес или недельный баланс (бот пользуется привилегированным управлением, см. LH-10 в аудите). Физические Android-устройства требуют проверки.
