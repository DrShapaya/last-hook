# 03. План действий и производство

## 0. Технологии
- **Движок:** Unity (2D/2.5D, URP) — быстрый для мобайла, сильная экосистема; альтернативы: Godot 4 (бесплатно, легко для 2D-физики), Defold.
- **Физика:** собственный фиксированный шаг + Box2D / Unity 2D Physics (DistanceJoint2D / SpringJoint2D) для каната; для детерминизма — собственный интегратор (Verlet).
- **Контент:** ScriptableObjects для материалов и чанков, редактор чанков (Tiled / Unity Tilemap).
- **Бэкенд (позже):** Firebase / PlayFab — лидерборды, daily seed, аналитика.
- **Аналитика:** Firebase/GameAnalytics (события: попытки, место смерти, высота, ретеншен).

## 1. Этапы (ориентировочно, соло/малая команда)

### Этап 0 — Подготовка (1 неделя)
- [ ] Зафиксировать столпы (см. README).
- [ ] Определить референсы (Getting Over It, Jump King, Spider-Man-подобные игры, Ski Safari, Hook Swing).
- [ ] Выбрать движок, настроить репозиторий, Git LFS.
- [ ] Определить целевое устройство (минимум: 3 ГБ RAM, 60 FPS).

### Этап 1 — Прототип «серой коробки» (2–3 недели) 🎯
**Цель:** убедиться, что core loop *приятный сам по себе*.
- [ ] Ввод: свайп → выстрел, тап → отпускание.
- [ ] Физика: герой-точка, канат (distance constraint), лебёдка, гравитация.
- [ ] Один материал (камень) и ручной тестовый уровень (≈ 100 м).
- [ ] Bullet-time + пунктир траектории.
- [ ] Камера, следящая вверх.
- [ ] Условие смерти.
- **Критерий готовности:** 5 внешних тестеров играют по 5 минут и **сами нажимают Retry** без просьб. Если нет — менять физику, а не добавлять контент.

### Этап 2 — Материалы и честность (3–4 недели)
- [ ] Материальная система (параметры `grip/durability/slide/bounce/impulse`).
- [ ] 6 материалов (корень, камень, лёд, ветка, стена, кость).
- [ ] Читаемость: подсветка валидных точек, цвета материалов, предупреждение перед сломом.
- [ ] «Золотое окно» отпускания (визуальный и звуковой сигнал).
- [ ] Реплей смерти (ghost-траектория).
- [ ] Автотест достижимости чанков.

### Этап 3 — Структура забега (3–4 недели)
- [ ] Чанки + процедурная сборка.
- [ ] 2 зоны (лес, скалы) полностью, переходы, чекпоинты.
- [ ] Падение/сейв, линия потери.
- [ ] Экран смерти, Retry, базовый HUD (высота, рекорд, шкала зон).

### Этап 4 — Мета-прокачка (2–3 недели)
- [ ] Валюта, магазин прокачки крюка (длина, сила, сцепление, импульс, лебёдка).
- [ ] Экономика (таблицы в Google Sheets, симуляция).
- [ ] Сохранение прогресса, облачный сейв.

### Этап 5 — Вертикальный срез (4–6 недель)
- [ ] Арт: финальный стиль для 2–3 зон, персонаж, VFX, звук.
- [ ] Полировка game feel (haptics, камера, SFX).
- [ ] Zone 3–4 (руины, лёд) и новые правила.
- [ ] Туториал без текста (первый забег учит через уровень).

### Этап 6 — Софт-лонч (4–6 недель)
- [ ] Выпуск в 1–2 небольших странах (напр. Канада, Филиппины, Нидерланды) для тестирования метрик.
- [ ] Цели: D1 ≥ 40 %, D7 ≥ 12–15 %, средняя сессия ≥ 6 мин, ≥ 5 попыток/сессия.
- [ ] Итерации баланса по аналитике (где умирают чаще всего).

### Этап 7 — Глобальный релиз и LiveOps (дальше)
- [ ] Зоны 5–6, второй крюк, Daily Run, лидерборды, события.
- [ ] Контент-план: новая зона/материал каждые 4–6 недель.
- [ ] TikTok/Reels/Shorts-кампания (см. ниже).

## 2. MVP: минимальный набор
- 1 механика (крюк) + 4 материала (камень, корень, ветка, лёд).
- 2 зоны.
- Прокачка: длина + импульс.
- Экран смерти + Retry + рекорд.
- Всё остальное — после проверки, что играть **приятно**.

## 3. Метрики успеха и анализ
| Метрика | Цель | Что делать, если ниже |
|---|---|---|
| Retry-rate после смерти | ≥ 75 % | Улучшить читаемость промахов, ускорить рестарт (<1 с) |
| Время до первого рекорда | 2–3 забега | Снизить сложность 1-й зоны |
| Средняя высота забега | растёт каждый день | Баланс прокачки, дейли-подсказки |
| Share rate клипов | ≥ 3 % | Улучшить авто-выбор клипов, добавить фильтры |
| D1/D7/D30 | 40/15/5 % | Мета-цели, миссии, события |

Heat-map смертей: на каждом чанке логировать точки гибели — сразу видно «несправедливые» места.

## 4. TikTok / вирусный план
1. **Игра, которая сама делает клипы:** авто-запись, кнопка «Поделиться», вертикальный формат, шаблон с высотой/зоной.
2. **Хук-моменты** (ветка-катапульта, сейв, «роковой миллиметр») — вырезать для рекламы.
3. **Хэштег-челлендж** (позже): «#СпасениеНаКрюке» — ежедневный сид; кто выше, тот выигрывает кастом-скин.
4. **Креативы для UA:** 6–15 сек, один момент, без текста; тестировать 10+ вариантов.
5. **Работа с блогерами:** выдавать ранний доступ, давать им «легенды» (скины/косметика).

## 5. Монетизация (детально)
- **Основной доход:** rewarded ads (второй шанс, x2 кристаллов, бесплатная прокачка).
- **IAP:** косметика (скины героя, цвет каната), «Без рекламы», стартовые наборы.
- **Принцип:** нельзя купить мастерство; можно купить скорость прогресса и красоту.
- **Не делать:** принудительные таймеры, лутбоксы с реальными деньгами, платные «спасения» после каждой смерти.

## 6. Риски и митигации
| Риск | Вероятность | Митигация |
|---|---|---|
| Физика «не цепляет» (скучно/раздражает) | Высокая | Этап 1 — только прототип; не продолжать, пока не весело |
| Несправедливые смерти | Средняя | Валидатор достижимости, heat-map, ghost-реплей |
| Слишком простой core loop → быстро надоедает | Средняя | Материалы, зоны, прокачка, события |
| Большой объём арта | Высокая | Модульные ассеты, палитра/шейдеры вместо уникальных текстур, оутсорс |
| Монетизация мешает гейм-фиелу | Средняя | Рекламы только между забегами; A/B тесты |
| Похожие игры на рынке | Средняя | Уникальные материалы + визуальный стиль + TikTok-моменты |

## 7. Ближайшие 7 дней (конкретно)
1. День 1: выбрать движок, создать проект, настроить портретный режим.
2. День 2: герой-точка, гравитация, камера вверх.
3. День 3: свайп → выстрел → зацеп (raycast).
4. День 4: канат + лебёдка + раскачка.
5. День 5: отпускание по тапу + bullet-time + пунктир.
6. День 6: тестовая стена (камень), смерть и рестарт.
7. День 7: тест на себе и 3–5 друзьях, заметки «что бесит / что цепляет».
