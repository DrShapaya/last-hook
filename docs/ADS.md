# Реклама Last Hook

Приложение в РСЯ: **Last Hook**, ID **20238117**.
Идентификаторы предоставлены владельцем 18 октября 2026 года.

| Место показа | Формат | ID рекламного блока |
|---|---|---|
| Возрождение после смерти | Реклама с вознаграждением | `R-M-20238117-1` |
| После прохождения уровня, перед следующим | Межстраничная реклама | `R-M-20238117-2` |
| Главное меню | Баннер | `R-M-20238117-3` |

Значения для релизной сборки сохранены в `game/data/yandex_ads.json`.
В запросы SDK следует передавать ID рекламного блока из таблицы; имена
`R-M-20238117-1_main`, `R-M-20238117-2_main` и `R-M-20238117-3_main`
не являются значениями этого конфига.

## Состояние подключения

Подключён **Yandex Mobile Ads 8.5.0** через собственный Godot Android v2
плагин `LastHookAds`. Исходники Android-модуля — `tools/android-ads/`,
собранный AAR и плагин экспорта — `game/addons/last_hook_ads/`.
Игровой сервис — `game/scripts/ads_service.gd`.

- Возрождение запускается кнопкой «Смотреть рекламу · возродиться».
  Сервис принимает событие SDK `onRewarded` только в ходе запрошенного
  показа. Игра возрождает героя после закрытия объявления, один раз,
  в той же попытке. Алмазы не тратятся; рюкзак и высота сохраняются.
  Преждевременное закрытие и ошибка показа возвращают к выбору продолжения.
  Подтверждённая награда сохраняется сразу: если Android завершит процесс
  до закрытия объявления, продолжение выдаётся при восстановлении попытки.
- Межстраничная реклама показывается после успешного прохождения горы,
  когда награда уже рассчитана и сохранена. Поражение и тренировка не
  вызывают показ. Если объявление не готово, игра сразу показывает результат;
  поздняя загрузка не прерывает следующую попытку.
- Баннер виден во вкладках главного меню. Под него резервируется полоса
  фактической высоты в пикселях, меню масштабируется в оставшуюся область.
  Во время восхождения, на модальных экранах и в полноэкранной рекламе
  баннер скрывается.
- На время открытия полноэкранной рекламы блокируются действия игры.
  Ошибки загрузки ограничены паузой 30 секунд до следующей попытки
  по действию пользователя; постоянного цикла повторных запросов нет.

## Тестовая и релизная сборки

**Debug APK** автоматически использует официальные демоблоки
`demo-rewarded-yandex`, `demo-interstitial-yandex`, `demo-banner-yandex`.
Это настоящие вызовы SDK с тестовыми объявлениями, без дохода.
**Release APK/AAB** использует три ID владельца из таблицы выше.
Приложение не подставляет согласие пользователя или возрастную категорию.

На Windows SDK не запускается. В отладочной Windows-версии сохранено
явно обозначенное тестовое продолжение без рекламы. На Android с SDK
эта кнопка заменена реальным рекламным продолжением даже в debug-сборке.

## Сборка и проверки

Для Gradle-экспорта нужны полный Android SDK (platform 36, build-tools
36.1.0) и JDK 21. Сокращённого `tools/android-sdk/` с одним adb недостаточно.

```powershell
./tools/build.ps1 -Target Android -AndroidSdkPath 'C:\Users\isaev\AppData\Local\Android\Sdk'
```

Скрипт подготавливает Android build template из установленных шаблонов
Godot 4.7.2, включает Gradle-экспорт, выполняет проверки и подписывает
отладочную APK. При первом запуске Gradle загружает зависимости.
Собранный AAR включён в проект. После изменения Java-исходников пересобрать:

```powershell
./tools/prepare_android_ads.ps1 -RebuildPlugin
```

Релиз экспортируется пресетом `Android` в режиме release с собственным
релизным ключом подписи, указанным в локальных настройках экспорта.
Ключи и пароли в репозиторий не добавлять.

`game/tests/test_ads.gd` проверяет жизненный цикл рекламы через имитацию
событий SDK, без запросов к рекламным блокам. Показы объявлений и действия
внешних Activity требуют отдельной проверки на Android.

На Android-эмуляторе API 36 проверены регистрация плагина, инициализация
SDK и встроенные проверки интеграции трёх форматов. Демо-баннер отображается
в меню и скрывается при старте. Реальный демопоказ rewarded завершился
возрождением: награда сохранена до закрытия, после закрытия попытка
продолжена, 10 алмазов остались в кошельке. Физический телефон и живые
рекламные блоки владельца пока не проверялись.
