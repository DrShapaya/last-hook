# Анимации цельного персонажа

В версии 0.10.6 игра использует `game/assets/art/explorer-whole-v3.png`, сцену `game/scenes/player_sprite.tscn` и контроллер `game/scripts/explorer_sprite.gd`. Изображение располагается на непрерывной сетке 40×40 ячеек; шейдер `game/shaders/explorer_sprite.gdshader` мягко меняет положение руки, ног, головы и рюкзака. Рисунок сохраняет соединения конечностей. Амплитуды ограничены для сохранения анатомии исходной картинки.

| Состояние | Движение |
|---|---|
| Ожидание | Дыхание, небольшое движение головы и рюкзака |
| Бросок крюка | Рука слегка вытягивается, корпус собирается |
| На канате | Наклон по скорости и направлению опоры, движение ног, инерция рюкзака |
| Полёт вверх | Ноги подтягиваются, корпус наклоняется по направлению полёта |
| Падение | Рука отводится, ноги опускаются и балансируют |
| Приземление | Короткое мягкое сжатие корпуса с возвратом к ожиданию |

Параметры позы сглаживаются экспоненциально по времени. Фаза движения непрерывна при смене состояния; анимация не начинается заново на каждом кадре. Разворот происходит постепенно, с порогом смены направления. Движение останавливается на паузе. Точка каната вычисляется по положению нарисованной кисти с учётом деформации и разворота.

**PreviewAnimations.cmd** показывает все шесть состояний одновременно. **PreviewSource.cmd** запускает игру из исходников. **Play.cmd** запускает собранную версию.

`game/tests/test_sprite_animation.gd` проверяет выбор состояний, плавность смены поз и направления, остановку на паузе, сходство при 30/120 FPS, привязку кисти и ограничение скачка при длинном кадре.

Старая модель из отдельных деталей остаётся в `player.tscn` как сохранённый вариант. Текущая игра её не загружает.
