# Собрать персонажа в Godot

Это инструкция для прежней составной модели. С версии 0.10.6 игра использует цельный PNG через `game/scenes/player_sprite.tscn`; изменения старой сборки не подменяют текущего героя. Анимации текущего героя описаны в [CHARACTER_ANIMATIONS.md](CHARACTER_ANIMATIONS.md).

Запусти **EditCharacter.cmd** из папки проекта. Он открывает сохранённую старую сцену `game/scenes/player.tscn`.

Это набор отдельных Sprite3D с прозрачными текстурами и суставами Node3D. Фотошоп не нужен.

## Первое открытие

1. Выбери вкладку **3D**, в дереве сцены слева — `Player`.
2. Нажми **F**, чтобы приблизить выделенный объект. В меню вида над сценой выбери **Front / Спереди** (также NumPad 1). В этом виде видны нужные X и Y, без перспективного искажения.
3. Раскрой дерево `Player`. Выбирай детали в дереве: так не попадёшь случайно в рюкзак или слой ткани.
4. Меняй положение и угол. Самый точный способ — справа **Inspector → Transform → Position / Rotation / Scale**. Для обычной сборки меняй Position X/Y, Rotation Z и Scale X/Y.
5. **Ctrl+S** сохраняет старую модель. **F6** запускает выбранную сцену. Остановить запуск — F8. **F5** запускает игру с текущим цельным персонажем.

Размеры в сцене небольшие: сдвиг 0,01 уже виден. Углы в инспекторе задаются в градусах. Колесо мыши приближает вид.

## Что выбирать

| Узел | Что меняется |
|---|---|
| `Head`, `Torso`, `Pelvis`, `Backpack` | Голова, куртка, шорты, рюкзак |
| `NearShoulder`, `FarShoulder` | Положение и угол всей руки; Near — ближняя, слева в исходном ракурсе |
| `…/UpperArm` | Картинка верхней части рукава |
| `…/Elbow` | Локоть и всё, что ниже него |
| `…/Elbow/Forearm` | Картинка предплечья |
| `…/Elbow/Hand` | Кисть целиком |
| `…/Hand/Glove` | Картинка перчатки |
| `NearHip`, `FarHip` | Положение и угол всей ноги |
| `…/Thigh`, `…/Knee/Shin`, `…/Knee/Ankle/Boot` | Картинки бедра, голени, ботинка |
| `…/Knee`, `…/Knee/Ankle` | Суставы колена и стопы |
| `FarShoulder/Elbow/Hand/Grip` | Точка, за которую кисть держит канат |

Чтобы переставить руку целиком, двигай **Shoulder**, а не только `UpperArm`. Чтобы изменить место локтя, двигай **Elbow**, затем подгони картинку рукава. Для ноги работает та же схема: **Hip → Knee → Ankle**. Длина руки для зацепа берётся из сохранённых положений суставов.

Узлы `_ClothFill`, `_ElbowSeam`, `_ShoulderSeam` закрывают стыки ткани. Их тоже можно подгонять; для общей сборки начни с основных деталей.

## Проверить позу без анимации

В старой модели корневой `Player` содержит флажки **Animate Limbs** и **Blinking Enabled** для движения конечностей и моргания. Они сохранены для использования этой сцены в будущем.

Спокойная поза берётся из сцены. При включённой анимации рука с крюком сгибается автоматически; точки крепления, размеры и рисунки остаются твоими.

Не переименовывай `Player`-дочерние узлы Head/Torso/Pelvis, Shoulder/Elbow/Hand, Hip/Knee/Ankle и Grip: игра находит их по этим именам. Картинки можно менять в свойстве **Texture** у Sprite3D; **Pixel Size** меняет размер картинки.

**PreviewSource.cmd** запускает текущую игру из исходников. **Play.cmd** при наличии EXE запускает уже собранную игру.

Когда закончишь, сохрани сцену. Для новых EXE/APK запусти в PowerShell из папки проекта `./tools/build.ps1 -Target All` или попроси собрать игру после твоих правок.
