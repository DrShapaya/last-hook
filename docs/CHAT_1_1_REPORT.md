# Чат 1.1 — отчёт: пересборка горы из скальных масс

Заменяет визуальную модель чата 1 (`docs/CHAT_1_VISUAL_REPORT.md` устарел в части поверхности). Аудит неудачного результата — `docs/CHAT_1_1_AUDIT.md`. Gameplay-координаты, коллизия, физика крюка, механика типов зацепов, маршруты, камера и нижняя зона не менялись (наборы `test_terrain`, `test_generation`, `test_routes`, `test_hook`, `test_integration` проходят).

## Реализовано

### Новые классы и контракты

| класс | файл | роль |
|---|---|---|
| `RockMassSpec` | `game/scripts/rock_mass_spec.gd` | одна скальная масса: замкнутое тело с собственными гранями |
| `RockSurfaceHit` | `game/scripts/rock_surface_hit.gd` | ответ единого запроса поверхности |
| `RockMassBuilder` | `game/scripts/rock_mass_builder.gd` | меш чанка из масс: тона групп граней и cavity в вершинах |
| `MassifVisuals` | `game/scripts/massif_visuals.gd` | раскладка масс по полосам 24 м, `surface_query`, монтаж, декор, landmark, дальние хребты |
| `SurfaceMount` (расширен) | `game/scripts/surface_mount.gd` | + `host_mass`, `surface_class`, `socket_center`, `socket_normal`, `embed_depth`, `contact_bounds`, `material_profile` |

**`RockMassSpec`** — `id`, `band`, `region`, `seed_stream` (947), `landform` (buttress, slab, overhang, arch, pillar, island, shelf, rubble), `role` (trunk, body, fill, seat, ledge_shelf, find_shelf, island, overhang, arch, rubble), `outer_contour` (силуэт в XY, выпуклый), `z_back` / `z_rim`, `inner_contour` + `inner_z` (поднятое кольцо фаски), `cap_points` / `cap_triangles` (лицо из 2–5 крупных плоскостей), `top_edges` / `bottom_edges` / `side_edges` / `inner_edges`, `neighbors`, `material_profile`, `faces` (каждый треугольник с классом). Классы граней: `face`, `top`, `side`, `underside`, `inner_arch`, `wall` (боковая стенка до `z_back`: не видна прямой камере, но даёт телу объём для теней). Контур — `RockMassSpec.block_contour`: повёрнутый и скошенный блок с неравно сколотыми углами и изломом длинных сторон, а не круг.

**`surface_query(point) → RockSurfaceHit`** — самая передняя масса в точке и её грань: `mass_id`, `position`, `normal`, `tangent`, `depth` (глубина внутри силуэта), `surface_class`, `material_profile`, `exposure`, `mount_root`. Через него работают `wall_depth`, `surface_normal`, `open_at`, `mount_at`, `mount_find`, площадки, декор и landmark. Если запрос пуст, декор не создаётся.

### Формирование массива (R1–R2)

Полоса 24 м собирается из масс в таком порядке: trunk (блоки вдоль маршрута, попеременно по сторонам) → set piece региона (overhang для `overhang`, окно-арка для `arch`/`ravine`) → body (большие глубокие блоки позади, не заходят в проём арки) → fill (держит коридор маршрута ±2.3 м на камне) → seat (ещё один обычный блок кучи, только если объект ничем не накрыт; не меньше 2.4 м) → полки площадок и находок → острова и столбы в стороне → rubble у подножий, вдали от объектов. Арка — окно в породе: подоконник, две опоры и перемычка; все грани, обращённые в проём, имеют класс `inner_arch`, сквозь проём видно небо. Overhang — блок с широкой собственной нижней гранью, отбрасывает тень. Массы отбрасывают реальные тени друг на друга (кроме battery, где теней нет вообще).

### Полки, платформы, монтаж (R3–R4)

- Площадка — масса `ledge_shelf`: верхняя кромка силуэта = игровая линия `top`, ширина ≥ ширины коллизии, толщина 1.05–1.3 м, один бок длинным скатом уходит в лицо, другой коротко обломан, задняя часть стоит в теле горы.
- Находка — на собственной широкой (1.5–2.8 м) кривобокой полке лица, которая выступает всего на 0.45 м перед хозяином; постамент `LootVisuals` больше не строится на этой горе (`provides_find_shelves()`), находка ставится на переднюю кромку полки (`mount_find`).
- Зацеп — оболочка в узкой нише (`socket_margin` 0.16, тень ниши ×0.45), без skirt и без камешков-чипов; тёмная рамка контура заменена мягкой линией. Тип и статус — на самом объекте.
- Опасный блок — без skirt и щебня у основания.
- `consume_anchor` убирает оболочку, нишу и контактную тень; запечённой тени в коже больше нет, пятна не остаётся.

### Материалы и профили (R5–R6)

`GripBiomeProfile.rock_material` для пяти профилей: `base_color`, `facet_palette`, `roughness`, `normal_strength`, `strata_scale`, `cavity_strength`, `top_light_tint`, `underside_tint`, `weathering_mask`, `decor_palette`.

| профиль | где | порода | особенности |
|---|---|---|---|
| forest | location 0, 0–40 м | серый известняк | слабая слоистость, мох, трава, корни под нависаниями |
| ruins | location 0, 40–60 м | тёсаный серый | сильный cavity |
| snow | location 0, 60–80 м | холодный серо-синий | снежные карнизы вместо травы, сосульки, снег на верхних гранях |
| desert | location 0, 80–100 м; location 1 | тёплый песчаник | сильная слоистость (`strata_scale` 1.4), пыль на верхах, кактусы, сухая трава |
| sky | location 0, 100+ м; location 2 | светлый пористый | мягкий cavity, голубоватые низы |

Шейдер `massif_rock.gdshader`: шероховатость, деталь и слоистость (`strata_scale`) берутся из профиля, текстура считается в мировых координатах (не тянется по стене). Cavity — в цвете вершин от масс, стоящих впереди. Верх и низ получают тона `top_light_tint` / `underside_tint`.

Дальний фон — горные хребты с освещённым и теневым склоном, снежные шапки для снежного и небесного профиля, ряд елей на ближнем слое в лесу; два слоя параллакса (в battery один).

### Свет (R7)

Сила тени солнца поднята с 0.27–0.28 до 0.44–0.46 (`main.gd::_apply_shadow_preset`), чтобы тени масс друг на друга читались; заполняющий свет окружения не менялся, тени остаются сине-серыми.

## Осталось исправить / не подтверждено

1. **Реальное Android-устройство не проверялось.** Debug APK собирается (`tools/build.ps1`), но startup и сцена на телефоне не запускались — по критерию 10 приёмка не закрыта, нужен запуск на устройстве.
2. Лица масс ещё проще, чем в референсе: 2–5 плоскостей на блок, мелкой ломки и сколов внутри лица нет; нормальной карты нет, деталь — процедурный шум шейдера.
3. Арки находятся только в регионах `arch`/`ravine` и только там, где рядом нет игровых объектов; в некоторых сидах регион может остаться без арки.
4. Полки находок одной породы с хозяином, но в плотных участках их много подряд; при желании ограничить частоту — это решение для чата 3 (раскладка находок).
5. Дальние хребты простые (6 граней на пик), без атмосферной перспективы по высоте.
