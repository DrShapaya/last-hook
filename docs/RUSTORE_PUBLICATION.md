# Карточка Last Hook для RuStore

Подготовлено для версии **0.11.0**, Android APK `com.lasthook.prototype`, versionCode `17`.

## Поля карточки

**Название:**

`Last Hook`

**Категория:**

`Игры → Аркады`

**Возрастное ограничение:**

`12+` — аркадная физика падения, игровой риск и встроенная реклама; реалистичного насилия, крови и оружия нет.

**Краткое описание** (до 80 символов):

`Цепляйся крюком, раскачивайся и покоряй гору.`

**Поисковые теги** (до 5):

`крюк`, `альпинизм`, `аркада`, `физика`, `гора`

**Полное описание:**

`Last Hook — аркадное восхождение по процедурной горе. Цепляйся крюком за выступы, раскачивайся на канате и доберись до вершины.`

`Управление рассчитано на один палец: выбирай направление, бросай крюк и удерживай раскачку на канате.`

`Каждая попытка проходит по маршруту с площадками, скалами, корнями и узкими окнами для броска. Крюк летит по дуге, канат огибает препятствия, а ошибка может отправить героя вниз. Собирай находки, улучшай снаряжение и открывай новые высоты.`

`Игра бесплатна, работает без обязательной регистрации и сохраняет прогресс на устройстве.`

`Создано с использованием Yandex Mobile Ads SDK.`

**Что нового в версии 0.11.0:**

`• Улучшено управление одним пальцем.`

`• Отпускание пальца на канате теперь только отцепляет героя.`

`• Улучшены камера, баллистика крюка, канат и сохранение попытки.`

## Декларация данных и рекламы

В консоли RuStore следует задекларировать **Yandex Mobile Ads SDK 8.5.0** и рекламную сеть **Yandex**.

Используемые рекламные форматы:

| Сценарий | Формат | Блок |
|---|---|---|
| Главное меню | Баннер | `R-M-20238117-3` |
| После прохождения горы | Межстраничная реклама | `R-M-20238117-2` |
| Возрождение после падения | Реклама с вознаграждением | `R-M-20238117-1` |

Для декларации SDK укажите:

- технические данные устройства и приложения — для работы SDK и показа рекламы;
- рекламный идентификатор Android (GAID/AD_ID) — для рекламы и оценки её показа;
- сведения о показах и взаимодействии с рекламой — для показа и измерения рекламы;
- местоположение, контакты, камера, микрофон и файлы пользователя приложением не запрашиваются.

Данные рекламы передаются рекламному сервису Yandex. Политика конфиденциальности должна быть опубликована по постоянной HTTPS-ссылке и добавлена в карточку RuStore и в приложение.

## Разрешения APK

- `INTERNET` — загрузка рекламных объявлений.
- `ACCESS_NETWORK_STATE` — определение доступности сети перед запросом рекламы.
- `VIBRATE` — тактильная обратная связь.
- `com.google.android.gms.permission.AD_ID` — рекламный идентификатор для Yandex Mobile Ads.

## Файлы для загрузки

Материалы для карточки находятся в [`Builds/RuStore`](../Builds/RuStore):

- `LastHook-release.apk` — готовый release APK для загрузки в RuStore;
- `LastHook-debug.apk` — тестовый APK; **не отправлять как финальную публичную версию**;
- `icon-512.png` — иконка 512×512;
- `01-gameplay.png` — игровой экран с виртуальным стиком;
- `02-reel.png` — экран удержания вертикального направления;
- `03-menu.png` — главное меню.

RuStore требует скриншоты PNG/JPG до 3 МБ, а для каждого типа устройства — минимум 3 скриншота; поэтому в папку положены три вертикальных изображения одной ориентации. Для черновика можно сначала загрузить два основных кадра, но перед отправкой на модерацию лучше добавить третий.

## Что нужно заполнить вручную

1. Вставить рабочий e-mail разработчика и, при наличии, сайт или группу ВКонтакте.
2. Разместить [`PRIVACY_POLICY_RU.md`](PRIVACY_POLICY_RU.md) на HTTPS-адресе и заменить ссылку в карточке.
3. В разделе безопасности RuStore подтвердить отсутствие чувствительных разрешений, кроме перечисленных сетевых и рекламных.
4. В разделе рекламы указать Yandex Mobile Ads SDK и все три рекламных блока.
5. Сохранить `last-hook-release.keystore` и файл пароля в безопасном месте: этот ключ нужен для всех будущих обновлений.
6. Загрузить `LastHook-release.apk`, иконку и три вертикальных скриншота, затем отправить версию 0.11.0 на модерацию.
