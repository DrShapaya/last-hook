# Last Hook — фантазийные локации и объекты зацепа

Созданы 8 октября 2026 встроенным инструментом imagegen. Референс стиля: `references/target-look-v2.png`.

Три портретные локации: зелёная скала, песчаные арки, ледяной пик. Центральная гора имеет сквозные отверстия, ущелья, отвесы и уступы; по обеим сторонам — небо и облака.

Отдельный прозрачный атлас: 3 × 3 объекта. Порядок слева направо, сверху вниз: мшистый уступ, ветка с листвой, корень, деревянная платформа, песчаный уступ, каменная арка, снежный уступ, ледяной выступ, железное кольцо на камне.

Это изображения для дальнейшего оформления. Подключение к сценам, коллизии и изменение генерации в эту задачу не входили.
