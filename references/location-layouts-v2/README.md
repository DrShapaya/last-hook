# Last Hook — референсы структуры локаций, версия 2

Созданы 8 октября 2026 года встроенным инструментом imagegen. Референс материалов и света: `references/target-look-v2.png`.

## Требования автора

- Это референсы игровой компоновки для будущей локации в 2,5D с параллаксом.
- Игровой массив примерно в три портретных экрана шириной; камера перемещается вверх и в стороны, игрок использует всю ширину.
- Игровая поверхность находится на одном удалении от камеры: масштаб одинаков по высоте, гора не уходит вдаль к вершине.
- За боковыми границами массива небо с облаками; вылет игрока в сторону за границу горы приводит к проигрышу.
- Объекты зацепа распределяются по левой, центральной и правой частям горы, образуют подъём с поперечными переходами.
- Локации отличаются строением, расположением пустот, уступов и препятствий, а не только цветом.

## Изображения

| Файл | Структура |
|---|---|
| `01-fractured-massif.png` | Широкий скальный массив, угловатые блоки, диагональные разломы и нерегулярные пустоты |
| `02-rootbound-cliffs.png` | Скала с гигантскими переплетёнными корнями, ветками и карманами под ними |
| `03-ruined-cliff-city.png` | Разрушенные террасы, кладка, балки, балконы и провалы горного города |
| `04-sheared-basalt.png` | Расколотые базальтовые пласты, консольные полки, колонны и открытые разломы |

Кадры показывают средний участок уровня: геометрия продолжается за верхним и нижним краем, без вершины. Дальний фон, облака, скальный массив и выступающие зацепы визуально обозначают будущие слои параллакса. Сами PNG — цельные референсы; разделение на слои, коллизии и проверка достижимости маршрутов требуют отдельной реализации. Игровой код не изменён.
